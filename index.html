NL Math 1201 Factoring Guide

1 Greatest Common Factor (GCF)

Golden Rule: ALWAYS check for a GCF first before trying any other factoring method!

6x² + 12x ➔ GCF is 6x ➔ 6x(x + 2)

2 Trinomials (a = 1): x² + bx + c

Find two numbers that multiply to c and add to b.

x² + 7x + 12 ➔ (x + 3)(x + 4) [Since 3×4=12 and 3+4=7]

3 Trinomials (a > 1): Decomposition / AC Method

  1. Find two numbers that multiply to a × c and add to b.
  2. Break middle term bx into two parts using these numbers.
  3. Factor by grouping.

2x² + 7x + 3 ➔ a×c = 6. Numbers: 6 and 1.
= 2x² + 6x + 1x + 3 ➔ 2x(x + 3) + 1(x + 3) ➔ (2x + 1)(x + 3)

4 Difference of Squares: a² - b²

Pattern: Two perfect square terms with a minus sign between them.

a² - b² = (a - b)(a + b)
Example: 4x² - 25 = (2x - 5)(2x + 5)
